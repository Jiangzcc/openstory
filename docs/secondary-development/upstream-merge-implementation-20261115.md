人民币售价、全面禁BYOK、默认私有、真实供应商/邮件、上游skills或npm发布、远程数据库与部署不纳入这次兼容同步。单纯合入后对U得到零冲突只是祖先关系，不计入结构收益；原试点对照与后续I/R/未来V对照按 [重构计划](fork-isolation-refactoring-plan-20261115.md) 分开保留。
