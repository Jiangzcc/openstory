# 管理员图片渠道

更新：2026-11-16。本文记录现行二开行为和边界，供应商样例及逐批验证保存在末尾历史入口。

## 来源与业务范围

- **上游已有**：图片生成/编辑、内置模型、Cloudflare Workflows、R2、组织钱包及生成后扣费。
- **二开已实现**：管理员图片渠道、内置/自定义绑定、动态参数目录、USD 按张规格价卡及冻结执行快照。
- **未实施**：人民币售价、版本化汇率成本核算和全面禁止 BYOK；沿用现有美元组织钱包、Stripe 及图片扣费节点，不新增人民币钱包迁移或在线支付渠道。

入口为 `/admin/models?tab=image-channels`，与默认及文本模型共享页面，页签写入 URL。
平台管理均经 `systemAdminMiddleware`；公开目录只返回能力与价卡，不暴露渠道地址、凭证及供应商成本。

## 配置、候选与身份

| 对象       | 当前契约                                                                      |
| ---------- | ----------------------------------------------------------------------------- |
| 渠道       | Base URL 含公共前缀，不含 `/images/generations`；只写平台 Key                 |
| 候选发现   | 只读目录，不触发推理；选择候选建立禁用草稿，不自动启用或推断能力/价格         |
| 内置绑定   | 保留原逻辑 ID、名称和作品引用，生成/编辑分别绑定准确供应商 ID，不重复目录条目 |
| 自定义绑定 | 使用稳定 `custom-image:` 身份；既有身份的上游 ID 不原地替换                   |
| 参数       | 按操作维护类型、默认值、枚举/范围和验证状态，包含参考、蒙版及安全标量扩展     |
| 价卡       | USD 每张，按操作及计费参数匹配，供应商原币种成本单独记录                      |

配置保存不等于参数真实生效；HTTP 200 或字段被接受也不是能力认证。
启用的内置绑定优先于其原 fal/native 路由，无关组织 Key 不改变绑定或免除平台余额预检。
停用内置绑定后新任务恢复原路由；停用自定义绑定保留可读身份并拒绝新执行。
已启用但操作、能力或价卡不可用时明确拒绝，不静默换渠道。

## 用户端规格与报价

创作页沿用比例、分辨率和最终数量 1/2/4 张，其他参数采用当前管理员默认，不增加高级协议控件。
共享规格解析按当前操作已验证的 `size` 枚举求实际尺寸，报价和提交使用同一结果并冻结。
只有自动尺寸时显示由模型决定，不伪造比例/分辨率；超出解码预算的固定规格不可选择。
优先独立任务每次原生 n=1；不能单张时，仅使用可精确表达最终张数的已验证 n。
复用作品不以旧隐藏参数覆盖当前基本控件；数量无法精确表达时提示，避免静默多生成。

更具体的价卡优先，同等具体度歧义或缺价在调用前拒绝。
单张销售价须精确表示为整数微美元，再乘实际数量；零价为显式免费，不静默舍入。
高分辨率预检、预占、实际请求及收费使用同一冻结规格，不借低规格估价建立预留。
Studio 字数参考按内置逻辑身份读取，自定义未知身份不猜测；费用显示沿用现有偏好及 USD 精度。

## 保存、凭证与快照

使用现有 `app_metadata` 的 `secondary-development:image-channels:v1` 及独立图片凭证记录，无新增表或迁移。
Key 沿用加密实现，管理读取仅返回提示和引用；变更已有地址需要新 Key，轮换产生不可变引用并保留旧记录。
配置普通保存与新凭证插入同一 D1 batch；保留主库读取、权限和会话隔离。
单管理员配置不并发，不维护 revision/CAS 或过期草稿协调。

触发端冻结准确绑定、能力、参数、价卡和凭证 ID，父子任务沿用同一配置。
执行只解密冻结凭证，不重读可变模型选择或价格；已启动任务不因后来改价或停用而改路。
已存默认图片身份可保持可读；新保存及执行分别校验，不能把可读身份当作可执行路由。

图片 wire 仅支持 v2 字典格式，对渠道、参数集和价卡集去重；v1 及旧平铺数组已退役。
图片路由 UTF-8 预算为 256 KiB，保存与触发均检查，禁用项不占执行快照预算。
超限不截断，可停用渠道恢复；该预算不是整个任务 payload、检查点或 Worker 堆的预算。

## 生成、校验与计费

兼容适配器使用既有官方 OpenAI SDK：JSON `/images/generations`，multipart `/images/edits`。
单参考使用 `image`，多参考保持有序 `image[]`；蒙版仅在配置验证通过时使用。
SDK 和付费生成步骤不自动重试，不切换供应商；参考素材经组织授权存储或限量下载读取。
请求等待、响应读取及输出下载总预算十分钟，生成并存储步骤预算十五分钟。
按实际中断信号区分超时与调用方取消，保留已观察的 HTTP 状态，错误日志不输出密钥或原始供应商响应。

交付前核验真实 MIME、尺寸、字节及像素解码；提前约束编码/像素/缓冲预算并释放 Photon 对象。
损坏图片或固定规格不符明确失败；自动尺寸存实际结果，不裁剪拉伸后冒充参数有效。
只交付并计量有效输出，数量不足按实际张数计费，超量不增加授权扣费。
全部输出生成与 R2 存储在同一个步骤，仅小型元数据穿过检查点。
生成并存储后按冻结价卡进入现有幂等扣费，再保存版本/尝试选中；未选中变体沿用原收费语义。

额外 app_metadata 尝试状态、输入摘要、D1 已存结果恢复及二次记录步骤已退役。
已完成检查点依上游机制回放，检查点持久化前中断后重放可能再次调用供应商。
账务幂等不保证供应商恰好执行一次，未使用预占按所属任务清理，已扣交易不因选中失败自动撤销。
当前 Studio 步骤只支持 `uploads` 数组，不保留旧单图结果兼容。

## 实现与升级检查

- `src/models/image-channels.ts`、`image-channel-parameters.ts`、`configured-image-specification.ts`：目录、参数和规格契约。
- `src/models/server/image-channel-service.ts`、`server/db/image-channels.ts`：保存、发现、加密凭证持久化。
- `src/models/workflow-image-model-routing.ts`：v2 wire、字典去重和容量限制。
- `src/stills/server/configured-image-generation.ts`、`workflows/configured-image-step.ts`：执行、同一步骤存储和中断边界。
- `src/billing/configured-image-*.ts` 及 `server/configured-image-billing.ts`：规格价卡、计划报价和实际扣费。

升级重点为目录/规格、上游工作流参数透传、claim、预占归属、真实 via、同一步存储及扣费时机。
不把图片协议套到视频 MediaVia；技术细节见 [模型配置架构](../architecture/model-configuration.md)。
