## 二开兼容适配

### 工作流与生成计划

- 生成计划采用上游 `{ units, speakerConflicts }` 返回，保留二开的估价准备、模型路由和价卡快照。
- 配音批次采用上游 `{ shots, reasonByShotId }` 返回，保留二开模型配置参数与失败原因持久化。
- 两处新口型同步子工作流透传 `scopedDb.models`，沿用父运行冻结的模型配置，不读取当前配置代替快照。
- 本轮新增 `referencePhotoUrl` 的旧角色参考表载荷在读取边界归一为 null，继续使用原无照片语义；非法字段类型仍拒绝，既有造型、面部参考与 rendering 校验保留。不读取当前角色照片、不改持久化步骤名、claim 或原哈希。

### 图片报价与图像理解

- 单角色参考表和计划参考表均按实际发送的面部参考或角色照片计算参考图数量，统一文生图/图生图预检、费用和预留金额；不支持 edit 的渠道在开始生成前拒绝。
- 新建角色/地点的图片描述读取管理员 vision 配置，沿用现有凭证解析、兼容渠道路由和用量计费。未绑定的原有渠道按现行规则解析。
- TanStack AI 新增的可选 `cancelRun` 不再被助手封装误判为必填；保留两种必需的 hydration 方法及原有 HTTP 错误和重连处理。

上述改动仅修正二开与上游新入口的连接，没有新增另一套计费、权限或模型调用体系。供应商模型能力和实际供应商收费仍需真实环境验证。

### 界面与国际化

- 采用上游新的角色/地点表单、`{ character }` 返回、图片处理中状态及放弃编辑确认，再接回既有翻译机制。
- 角色替换、参考照、录音上传、口型同步、历史来源、放弃编辑确认及说话人冲突补齐中英翻译；仅改变呈现层，用户角色名、台词、音频和文件名保持原文。
- 公开帮助内容中三篇文档的 11 段新增/变化英文原文键同步中英文语言包；Markdown 的链接、代码块和锚点仍由既有机制保留。
- 上游英文 E2E 通过测试夹具显式设置语言 Cookie，自建登录上下文同样覆盖。另加无 Cookie 时默认中文、切换英文、刷新保持及切回中文的浏览器回归；产品默认语言仍为简体中文。
- 修正二开增强脚本入口的检查顺序：未登录时先打开登录框并保留增强意图，再对已登录请求检查模型配置是否就绪，避免配置加载期间静默丢弃点击；登录后恢复仍等待完整配置，模型校验和真实请求前的保护保留。
- 场景叙事保存成功后，将服务端确认结果合入当前剧集对应的场景缓存，保留结构、失效状态刷新，避免重复失效刷新期间继续显示旧标题；服务端按保存结果中的不可变版本 ID 返回对应脚本，避免缓存旧脚本与新版本号混用，不改变全局 QueryClient。回归覆盖刷新仍在进行时的新标题、脚本与版本一致、失败与未缓存场景，边界见 [场景编辑缓存](../architecture/scene-editor-cache.md)。
