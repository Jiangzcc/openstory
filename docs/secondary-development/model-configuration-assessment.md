# 管理员默认模型配置

## 已确认范围

用户确认本次只实现“管理员调整默认推荐”和“管理员调整内部固定模型”。现有用户选模入口继续复用；不增加模型上下架、供应商管理、人民币售价、用户账号级偏好或任意模型 ID 接入。

本次基于 develop 的 190bbf555e5748a04e1b42400da0d050ec637916 开始实施。上游已有模型目录、用户选择器、管理权限、供应商适配和工作流基础；本次二开新增管理员配置、持久化和实际调用接入。

## 原有行为与动机

主创作模型可以由用户选择，但推荐值分散在通用默认、Turbo、Quality 和新建序列设置中。拆场景、素材识别、提示词辅助、封面、分镜草图和视频理解使用独立固定模型；修改主分析模型不会更换这些内部模型。运营方需要直接在后台调整这些默认值，以控制实际使用的模型组合。

## 配置页面

入口：管理菜单 → 模型配置，路径 /admin/models。沿用现有后台和中英文语言切换。

| 分组         | 可配置项                                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------- |
| 通用默认     | 分析、图片、视频、音乐、新建序列视频                                                                          |
| Turbo 推荐   | 分析、图片、视频、音乐                                                                                        |
| Quality 推荐 | 分析、图片、视频、音乐                                                                                        |
| 内部步骤     | 拆场景、图片理解、Studio 提示词草拟、提示词精简、风格推荐、序列封面、分镜草图、上传视频人物检查、助手视频理解 |

共 22 项。恢复代码默认和撤销修改只操作表单，点击保存后才持久化。候选来自现有目录：图片理解只允许视觉模型；视频理解只允许已有原生 Google 适配的模型。保存配置不会增加供应商适配能力，也不配置供应商密钥。

## 存储与权限

复用现有 app_metadata 表，用 secondary-development:model-configuration:v1 保存一份 JSON。单条写入保证整份配置一起生效，不新增表、不修改历史业务数据、不需要新数据库迁移。

SQL 位于模型域 server/db/model-configuration.ts，经 ScopedDb 组合。普通范围只暴露 get；系统管理员范围才暴露 save。管理读取和保存都通过 systemAdminMiddleware 鉴权。用户端读取的公共接口仅返回模型 ID，不包含密钥或用户资料，以保留上游匿名浏览能力。

配置未保存时使用原代码默认。读取旧的部分配置时补齐新增字段；无效保存会被服务端拒绝。配置存储损坏或目录发生不兼容变更会明确失败，不吞掉错误回退。

## 生效规则

- 已有作品、产物和用户显式选择优先；后台修改不会批量重写它们。
- 没有本地模型覆盖时，新创作、Studio 和助手采用当前平台配置。Turbo／Quality 切换使用对应推荐。
- 旧 localStorage 全量记录无法可靠区分用户选择与当时的默认，因此保守视为已有偏好；新的偏好记录只保存覆盖项。
- 创建入口在应用层补齐未传入的模型，再执行原 schema 校验。兼容历史的 schema／SQL 默认常量保留。
- 新建视频仍进行供应商和比例能力检查；不可用时沿用原入口的回退规则。
- 管理员专用内部模型在服务端决定，客户端传入的同名快照不能覆盖它。
- 启动工作流时保存一份配置快照；子任务和失败处理继承同一份。运行中不读取当前模型配置。旧任务缺少字段时只用代码默认，不临时读取 D1。

## 接入范围与升级冲突

新增配置模块、配置表单、查询 hook 和存储方法是独立扩展。必要上游桥接点为 ScopedDb 组合、工作流触发／父子继承／base、现有默认值消费方及内部模型调用点。多个工作流文件仅补一项快照传递，不改变生成阶段或供应商路由。

上游升级重点复核模型目录 ID 与能力、generation-mode、用户偏好格式、创建 schema 及入口、ScopedDb 的请求／工作流边界、工作流 payload、固定辅助调用的计费位置。新场景接入应增加显式字段并继续遵守任务快照，不能在工作流里重新读配置。

## 边界

- ElevenLabs 台词合成和语音转换目前分别只有一个已接入模型，保留适配器约束；本次不提供任意填写 ID 来更换这些模型。
- 区域限制与内容拦截后的备用模型属于恢复策略，保持原有配置和行为。
- 供应商凭证解析、实际调用的 via、重试和产物存储语义保持原有规则。
- 实际用量费用记录使用本次实际模型与 via；LLM 的前置费用估算仍沿用上游固定近似值，不声称已经按各模型精确估价。本次不涉及人民币售价或结算。
- 不执行真实付费生成、真实邮件发送或部署。
