## 动态二开发现与必要适配

本轮三方比较发现 1101 个本地候选差异路径，与上游有 22 个精确交叉路径。审查还沿调用链核对了不在同一文件的语言、模型配置、渠道凭证、报价和预占契约。

### 静帧与任务语言

上游新增 `derivedStillPrompt` 在触发时从已选 shot spec 派生提示词，不再把包含对白的场景剧本作为静帧回退。这是上游能力。本地 `deriveStillPrompt` 另有语言参数，因此为新 helper 增加必填 `promptLocale`，在单镜头、添加模型、智能重试三个触发入口传入当前任务语言；用户构图、地点、风格及内容保持原值。

本地单镜头入口原来的预校验会在没有已选提示词时提前拒绝，挡住上游的新规格派生路径。适配后只有显式空白 override 在扣费前拒绝，缺少 override 由准备链解析已选提示词或规格。中英真实本地 D1 测试覆盖派生、渠道报价、预占和 Mock 派发；显式空白覆盖不派发、不预占。

`UpdateStaleShotsWorkflow` 保留 `deriveMissingPrompt: false`，不在运行中读取可变的规格指针。无可用提示词时转换为不可重试错误。渠道报价、模型配置、路由与凭证快照、reservation 和 claim 行为继续沿用现有二开实现。

`skipped` 与 `skippedShots` 贯穿结果、计划和 MCP schema；MCP 给模型的技术 summary 保留英文，网页 toast 使用英文原文键并补齐中英资源。帮助文档、依赖图和新错误提示同步更新资源，未翻译协议字段、模型 ID 或金额单位。

### 地点名称

上游先锁定场景标记的地点，再允许提示词在其中缩小范围，避免旧提示词覆盖用户刚选择的新地点；精确匹配优先于子串，区分公寓与公寓浴室。

新增归一化原本只保留 ASCII。回归测试证明 `Set 厨房` 与 `Set 卧室` 会同时被选中。独立兼容修复改为保留 Unicode 字母和数字，保持中文用户地点名称的区分，不改变组织地点及 link 的归属结构。

fal `/storage/` 现在按上游设计绕过代理。浏览器验证保持 `E2E_TEST=true`、`E2E_RECORD=0`；`external-url` 的 replay 分支在构造 File 或 fal client 前返回 URL 字符串，结果媒体从录制静态资源下载后写入本地 R2。没有启用真实录制或调用付费供应商。

### 实时订阅

`connected` 从 HTTP 打开时改为所有 DO channel 的订阅响应到齐后发送。客户端在该信号到达后失效 sequence 数据、shots 和提示词预览缓存，覆盖首次订阅与浏览器 SSE 重连。保留此前本地 E2E 同步 helpers。

上游 pump 仅在首次 DO 订阅发 ready；DO 内部断流后自行重订阅不会再向浏览器发送新的 `connected`。本次不能宣称所有断线和漏事件都能恢复。

### 预览数据库清理

上游 sweep 原本在缺少环境变量时查询固定上游仓库的 PR。二开仓库的同号 PR 状态可能不同，因此本地改为必须显式提供 `GITHUB_REPOSITORY=owner/repo`，并在任何 registry/D1 访问之前同时校验仓库与 GitHub token。CI 已自带仓库变量；手动用法和两种语言资源同步说明。

Mock 测试覆盖缺少或无效仓库、缺少 token 时零网络访问，以及查询指定 fork 且保留打开 PR 的数据库。实际清理范围仍由上游的精确数据库名称、closed PR、当前基线 UUID 和 discard 再检查决定。本次没有执行远程 sweep；即使仅列出候选，registry 初始化也可能写入控制表。

最终复审另以真实函数和全量 HTTP Mock 复现清理与提升竞态：`discard` 读到旧基线后，`promote` 可以先将目标提升为新基线，随后删除继续执行，导致 registry 指向已删除的库。因此补了独立修复：复用现有 `ready=-1` 原子声明删除占用，包含没有 fork 记录的孤儿库；promote 的单条 CAS 同时检查 fork 的 PR、UUID、revision 和 ready 状态。`markReady` 与 `fork` 不得复活删除占用；删除失败保留占用供重试，成功后仅清理匹配 UUID 和删除状态的记录。没有新增字段或 schema migration。

该修复将控制表查询从按 SQL 字符串模拟状态切换改为仓库的真实 SQLite/D1 测试适配器，外部 HTTP 和子进程继续 Mock。两种竞争顺序、孤儿库、初始 NULL 基线、不同 UUID、删除失败重试及远端已不存在的恢复路径均有断言。远程 Cloudflare 行为仍未实际执行。
