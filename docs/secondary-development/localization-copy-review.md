# 中文文案语境复审

本轮在 `develop` 上复审现有国际化文案，只调整显示层与语言资源。上游已有创作、计费、模型调用和授权行为保持原有范围；此前完成的 i18n 接入与目录整理属于二开已实现，本轮是在此基础上的中文文案修订。

## 范围与修改方式

复核 24 个命名空间的 4,415 条既有资源，涵盖账号与邮件、创作界面、管理页面、公开页面、帮助文档及条款。调整其中 1,322 条中文文案，另外在角色音色命名空间补齐 11 个缺失键，中英文资源保持对应。英文原文继续作为键，不更改路由、用户内容、模型标识或提交给模型的提示词。

依据实际组件、调用参数和领域文档确定措辞，统一术语记录在 [GLOSSARY.md](../../GLOSSARY.md)。原有资源中无需调整的内容保留。

## 主要修订

| 场景         | 原有表达的问题                                        | 本轮表达与依据                                                                     |
| ------------ | ----------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 创作项目     | “创作序列”不符合普通创作者的使用习惯                  | 用“作品”指 Sequence；场景、镜头、地点分别保留不同含义，作品也与导出的成片区分      |
| 依赖状态     | 将 stale/out of date 译为“已过期”，容易误认为文件失效 | 改为“待更新”，说明相关输入发生修改；OTP、临时音色及七天预览的真实到期仍使用“过期”  |
| 视频预览     | 将低成本 480p 视频称为“草稿”，与剧本草稿混淆          | 使用“预览版 / 正式版”，保留 480p、1080p 和七天期限                                 |
| 角色配音     | 角色音色、候选音色和具体对白音频混称“声音”“朗读版本”  | 按实际对象分别使用“音色”“候选音色”“配音版本”                                       |
| 角色与地点图 | 设定图、上传照片及卡片小图容易混淆                    | 区分“设定图”“参考照片”“设定图缩略图”；地点小图不称为人物肖像                       |
| 镜头编辑     | ShotSpec 直译为“镜头规格”，重建与重写混用             | 使用“镜头设定”；依据保存的设定重建提示词，与通过 AI 改写镜头区分                   |
| 创作按钮     | “增强剧本”“缩短提示词”“再次使用”等表达生硬            | 使用“润色剧本”“精简提示词”“复用设置”，并与帮助文档对齐                             |
| 模型选择     | “Format”实际筛选画面比例，“Set”表示应用模型           | 使用“画面比例”“应用”，说明生成结果与当前采用的模型之间的区别                       |
| 管理状态     | “Triaged”直译为“已分诊”                               | 依据反馈处理流程译为“已受理”                                                       |
| 扣款失败     | “Card declined”误译为“拒付”                           | 使用“银行卡扣款未通过”，避免与 chargeback 混淆                                     |
| 移除与采用   | 部分文案未说清是否删除文件、是否影响其他作品          | 根据实际共享关系、选择指针及撤销行为说明影响，不将移除描述为永久删除               |
| 风格预设     | 大量名词堆叠和直译不便于选择                          | 按摄影、布光、构图及适用场景润色描述；只翻译系统目录，用户自定义风格名称仍保留原文 |

帮助文档同步这些术语，并补全继续生成说明中遗漏的参考资源失败范围与新音色绑定关系。开发者说明保留代码示例、字段、端点、模型名称和链接。隐私政策及服务条款仅修正中文语法和术语，保留上游日期、权利义务、费用规则及法律含义；本轮不构成正式平台条款的业务或法律审核。
