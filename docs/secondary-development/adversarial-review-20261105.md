## 保留并核查的二开契约

- 管理员模型与渠道接口仍由 systemAdminMiddleware 授权，组织 owner/admin 身份本身不授予平台配置权限。
- 内置文本模型使用适用的组织凭证优先规则；管理员兼容渠道继续是平台来源。自定义模型及已选渠道失败不跨渠道兜底。
- 工作流由可信服务端生成快照；父子派生、排队执行和重试继续沿用原快照，轮换保留旧凭证引用。停用当前渠道不会改写已经启动的任务。
- 公开模型目录不返回密钥、密文、渠道地址、上游模型 ID 或凭证引用。延迟响应修复处理客户端缓存，没有回显秘密或增加服务端权限。
- 按用户确认的单管理员边界，保持原默认配置读写接口。本轮无 schema 修改或数据迁移。
