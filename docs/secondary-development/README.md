## 使用规则

- 业务决定以 [规则确认](confirmation.md) 和根 `AGENTS.md` 为准；实现契约同时核对对应 `docs/architecture/` 及当前源码。
- 每项变更区分“上游已有”“二开已实现”“二开计划”“待验证”，说明原行为、动机、范围和实际证据。
- 已取消个人独立人民币钱包、新增商业卡密、管理员默认不浏览作品、旧格式兼容及额外恢复等规划，不从旧报告重新派生任务。
- 当前继续显式翻译；编译国际化试点未合入。静态面包屑已集中翻译，动态用户内容保持原文。
- 上游维护的主要目标仍是减少真实升级成本。文档清理、测试数量或局部源码减少不能证明未来冲突已下降。
- 新的完成记录优先写到现行主题文档；原始日志放本地归档，不为同一主题持续增加日期报告。
