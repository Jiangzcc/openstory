日期：2026-11-07。实施基线：`develop` 的 `94d446f48`；上游合入基线仍为 `003e2df7c4986fc236ea9a1c67c3f18089874d48`。用户已授权实施本方案。以下区分已有能力、实际改动和验证边界；提交状态以 Git 记录为准。

## 原有行为与需求

上游已有 82 个预置风格、每种风格的示例、风格选择与推荐、自动风格、作品级风格配方快照及版本记录。上游也已有由镜头规格派生提示词、供应商适配和提示词版本保存。它们均为复用基础，不计为本次二开新增。

此前二开已翻译风格名称、简介、字段标题与按钮，也已通过 `promptLocale` 选择中英文系统指令。但详情的氛围、美术、布光、调色、运镜、参考描述与标签仍直接显示英文；试用和随机示例仍使用英文语料。实际生成读取原始英文配方，因此中文系统指令不等于中文风格内容。

本次二开补齐平台风格内容与示例的中英资源，并让新选用的配方在进入作品快照前按请求语言解析；补充中文创作描述的输出要求及自然语言组装。目标是让平台内容和新生成描述随语言选择，不保证供应商请求完全没有英文。

资源复核另外校正两处中文配方措辞，保留原文的含义、具体细节与限制；未改动平台英文目录。

## 网页展示与草稿

- 详情弹窗沿用已有组件，在配置值、参考描述和标签处接入模板内容翻译；英文模式显示原文。
- 新建页的试用预填、编辑器内试用、随机示例及明确选择另一示例风格时按当前语言选择文本。
- 风格页“使用此风格”沿用上游的只选择风格行为；“试用”才同时带入示例正文。
- 切换语言不替换编辑框已有文字，不把语言加入 `composerKey`，不因切语言重挂载编辑器。用户改过的示例继续按用户草稿保存。
- 平台目录的浏览展示可以随界面语言变化；已保存的作品配方与提示词继续展示真实保存内容，不将当前译文伪装成历史提交正文。
- 原有样片生成和评估脚本继续使用原英文示例，既有视频不因网页示例翻译重新生成。

## 实际配方与工作流

`resolveStyleSource` 在可信服务层读取可访问风格，并按请求的 `promptLocale` 解析平台配方。新建作品把解析结果作为 `resolvedStyleConfig` 交给现有 `sequences.create`；数据库层只接配方，不接语言上下文。版本行与选择指针继续通过已有 batch 写入。

显式选择另一配方的内部写入同样可传入已解析配方，追加 `switched` 版本；没有风格选择时拒绝单独提交解析结果。网页现有改变剧本或风格的重新生成流程创建新作品，本次没有新增原作品内的风格历史恢复界面。

生成、子任务、继续与重试读取作品已保存的实际配方快照。目录后续被编辑、运营更新译文或用户切换界面语言，都不重新解析已有快照。复制已生成的自动风格读取来源作品快照，避免被后来变化的风格目录行替换。

Continue、Update all、fresh handoff 与预览规划显式传入当前任务的 `promptLocale`，在冻结计划时选择自然光等系统兜底描述的语言。已有光线、时间、地点及用户描述保留原文；纯内容计划 DTO 不新增语言字段，哈希结构不变。

`styleConfigHashBody`、提示词输入哈希字段、快照验证与依赖边保持原有设计，语言字段不进入哈希。中文配方本身是真实输入，保存后由生成侧与过期判断侧读取同一份内容。明确换用另一份配方会按原有内容变化规则产生新版本和待更新状态；单纯切界面语言不会。

没有新增表、字段、迁移、授权、钱包或计费流程。原有角色与地点设定图读取自身设定的 `rendering`，风格配方写入继续保留它们的生成声明。`Photoreal live action` 等参与精确比较的内部常量保持原值。

## 新生成描述与供应商格式

中文场景分析、设定提取、镜头规格、自动风格及镜头重写明确要求新编写的自由描述使用简体中文。用户已有姓名、指定画面文字、对白、逐字引用、ID、引用 token、Schema 字段及限定枚举保持原值。中文风格名称和参考示例不再使用英文示例引导。

静帧与动态提示词的固定运镜标签、自然光兜底、导演风格说明、海报与预览说明按调用语言组装。视频的单镜头、合镜、长度预检和请求预览传递同一语言；有声、静音、禁止背景音乐、连续镜头、音轨保留及口型同步的自然语言说明有中英文版本。

供应商语法保持原样，包括 Seedance 的时间标记、`cut to`、引用分隔符与音频 token，Kling 的 `multi_prompt` 时长结构，以及 MiniMax 的 `<d>`、`[English]`、`overall_soundscape`、`non_diegetic_music: N/A`。`[English]` 沿用已有对白适配规则，不由界面语言推断对白语言。用户已写的动态描述、环境声与对白不会被整段替换或自动翻译。

中文拒绝软化模板改用中文自由描述，保留原安全、内容与供应商标记约束；英文模板保持原文。平台风格推荐和剧本增强使用同一配方解析，避免展示、增强与创建读取不同语言的目录内容。助手继续沿内部请求语言，外部 API/MCP 继续沿现有入口的英文默认值。

旧英文规格的纯重建仍从旧规格派生，不调用模型翻译；已有作品切换界面语言后可能继续含有原英文配方或用户内容。需要另一种语言的创作内容时，应通过明确的新创作或重写动作生成新内容，不借语言切换覆盖存量。
