## 上游已有与本批二开

上游已有元素 bible/占位行、稳定 ID 和可改名 token、图片生成与同一步存储、软删除、并发分项执行、组织钱包扣费和溯源。本批修复其发布阶段的归属与并发缺口，不新增模型、计价、组织或支付能力。

UpdateStale 将显式 Storyboard 根/可信 claim 传到元素子任务，并覆盖旧 references payload 中的身份。只有真实 Storyboard 父提示允许实例 ID 回退，不能从 UpdateStale 父 ID 或前缀猜测根。独立入口保留。

窄 `publishGenerated` 在一个 D1 batch 中条件填充空行、条件插入新行并读取最终候选。实际 SQL 校验组织、序列、真实关系；绑定调用还要求当前根/显式可信 claim 和 processing。最终目标不存在时整批失败回滚。前后检查覆盖复用/空输入/异常，不能代替 SQL 授权。

ID 优先兼容改名；外序列或已删除 ID 不回退到另一个 token；已删除 token 继续保留身份。已有上传或较早生成结果原样返回，占位只填 URL/path/时间；初始行保持原默认值和生成元数据。工作流前置读取先校验序列访问和实际行关系，再返回最小对象。

生成、存储、usage、扣费、溯源和 ingest 的原持久步骤名、记账身份、模型、语言、上限与并发保留。已发生费用和生成事实先记录，之后即使换主拒绝发布也不抹除。确认丢失归属在步骤内不可重试；未知校验与引擎中断保留原原因，中断在分项汇总中优先。根绑定结果增加末尾持久检查，包含空结果。

## 边界与后续

这不是整根取消或退款协议。已授权 batch、费用、溯源和存储对象不回滚；发布后的独立编辑仍可改变素材。持久 checkpoint 的缓存命中不重新执行检查，包含新增完成检查自身的缓存；不会修复全缓存旧任务或没有可信根的旧后代。

角色/look/地点/声音等其它后代、完整选择/事件/preview/父通知、共享资格并发、邮件和独立入口继续开放。真实 Workerd/D1 重启回放、多实例、浏览器、供应商终止和钱包结算尚未验收。未添加 schema、迁移、依赖、binding、cron、哈希或读取 hatch；未推送、部署或调用付费模型。

精确范围和源码指纹见 [implementation.json](implementation.json)，首次失败、复跑、替身、审查及任务临时产物哈希见 [verification-results.json](verification-results.json)。临时产物在收尾核对后清理。
