## 本批实现

- 海报实际 UPDATE 同时检查组织、序列、当前根/显式可信 claim 和 processing；普通更新保持原契约。
- 已发生的用量与扣费先完成；拒绝发布不发事件，并在启动孩子前退出，只释放该任务的剩余预留。
- 海报事件保留根身份，但客户端只据此读取当前详情，不采用事件 URL。取消旧请求、无观察者读取、连续通知补读和启动确认各有明确边界。
- 刷新按真实非手工查询成功确认；取消后返回的旧缓存不算成功。同步建立查询生命周期，避免空缓存清空后被后台请求填回。
- 不新增 schema、迁移、依赖、binding、cron、read hatch 或边界例外；原有 generation/save/usage/debit step 名、模型和费用字段保留。
