## 范围与实现状态

上游已有页面、组织权限、钱包、兑换卡、模型调用、帮助内容和邮件模板；二开增加默认简体中文、英文切换及独立语言资源，不改变这些业务规则。商业规划以[规则确认单](confirmation.md)为准。

现有用户端、管理端、公开页面、帮助内容及账号相关邮件已接入中英文；系统指令按任务语言选择，独有规则见[系统指令契约](system-prompt-localization.md)。代码接入不表示所有业务状态、外部服务或真实生成质量已验收。

## 默认语言与请求隔离

- 支持 `zh-CN`、`en`；缺少、非法或不支持的偏好均默认中文，浏览器英文偏好不覆盖此规则。
- `openstory_locale` Cookie 保存当前浏览器选择；刷新、导航及直接打开子页面保持，不做账号跨设备同步。
- SSR 每个请求创建独立 i18next 实例，传递并水合语言；页面标题与 `html lang` 随当前界面同步。
- 语言切换只更新显示及偏好，不清空草稿、不重挂载编辑器、不重发业务请求；保存失败应显示现有失败反馈。
- 未登录首页在右上角“登录”左侧复用 `LanguageSwitcher`；语言按钮可用时及菜单选项显示手型鼠标，站内复用该组件的入口一致生效。
- 账号邮件使用发起请求的语言，异步发送不跟随后续切换；请求间不共享可变语言。
- 异步界面通知使用 `useLiveTranslation` 在完成时读取当前语言；订阅和任务 effect 不因翻译函数绑定变化重新执行。

## 目录与翻译约定

| 所有者                          | 职责                                                                          |
| ------------------------------- | ----------------------------------------------------------------------------- |
| `src/platform/i18n/`            | 语言定义、偏好解析、实例工厂、纯函数及 auth/common/mail/mcp-views 平台资源    |
| `src/ui/i18n/`                  | 应用资源组装、业务语言包、React hooks、切换组件、页面标题与 Markdown 显示适配 |
| `src/look/localization/`        | 平台风格内容与示例资源、模板配方解析；继续归风格域所有                        |
| `src/ui/layout/breadcrumbs.tsx` | 静态面包屑的集中翻译及现有解析、导航、移动端显示                              |

- 以完整英文原文作键，如 `t('Welcome')`，按命名空间拆分独立中英文资源；不改为语义键。
- `keySeparator`、`nsSeparator` 为 `false`，句点、冒号和标点均为普通键内容；英文改动须同步调用和两种资源。
- 使用完整句子、插值、复数及 `Trans` 受控组件；不拼接固定语序、不注入任意 HTML、不做全局 DOM 文本替换。
- 已知原文允许明确英文回退，未知上游内容原样保留；回退不表示新增内容已翻译，覆盖检查仍须发现缺键。
- 用户命名、剧本、对白、上传文件名、已存生成内容、模型/供应商品牌和原始诊断保持原值；不能仅凭名称推断模板身份。
- 金额、精度、数值与真实币种保持，不把美元符号换成人民币。中文术语按根目录 `GLOSSARY.md` 维护。
- 帮助 Markdown 保留代码、链接及英文锚点；肖像授权显示中文时仍展示参与签署证据的英文原文，不改哈希或版本。

## 面包屑、助手与风格的特殊边界

静态路由声明沿用上游字符串、对象或数组，由现有 Breadcrumbs 翻译字符串标签。函数返回的动态面包屑只翻译显式 `translationKey`；用户同名内容和 React 节点保持，导航的 `to`、`search`、`keepOnMobile` 继续生效。2026-11-16 已完成这项集中接入；编译国际化和受限静态 JSX 试点均未采用，当前继续显式翻译，无编译转换器。

内置建议的按钮显示与点击填入/发送使用同一份当前译文；切换语言不替换已有输入。助手作品卡片复用共享 MCP Apps HTML，站内宿主传 `hostContext.locale` 并通知语言变化；外部宿主未提供 locale 时回退英文。`openstory/styleNames` 是本站扩展，按合法风格 ID 与 `isTemplate === true` 翻译名称，不要求外部宿主提供该扩展。语言更新只重绘显示，不改工具结果、历史或重新启动轮询。

平台风格的名称、简介、配置描述、参考、标签及试用/随机示例按已知完整原文翻译；未知字段回退。实际配方只在服务端确认 `isTemplate === true` 后逐字段解析，非模板、修改后的未知字段、颜色、数值及枚举保留。`motion.pace` 译文仅供显示。

新选用配方经 `resolveStyleSource` 按请求语言解析并进入作品快照；后续生成、继续、重试和复制已生成自动风格使用实际快照，不因目录或译文更新重新解析。切界面语言不改已有版本或待更新状态。中文新创作描述及供应商格式边界见系统指令契约。

“使用此风格”仍只选择风格，“试用”才带入示例。切换语言不替换编辑框正文；连续灵感选择保留同一编辑器，真实外部导航和登录后的草稿恢复沿原流程处理。原样片生成脚本继续使用英文示例，不因网页翻译重录视频。

## 上游更新与差异复核

从仓库根目录运行现有只读报告：

```bash
# HEAD 对当前暂存、未暂存及未忽略的未跟踪内容
bun scripts/check-localization-changes.ts --base HEAD --out .tmp/localization-review.json

# 两个固定提交或引用
bun scripts/check-localization-changes.ts --base HEAD~1 --head HEAD --out .tmp/localization-review.json
```

不传 `--out` 时只输出 JSON；输出不得覆盖比较两侧输入。工作树扫描期间应避免并发编辑；该扫描不提供事务式快照，提交间比较使用固定提交内容。

报告固定 `status=report-only`，列出 UI 静态键/JSX、动态键、命名空间提示、双语资源、帮助路径、系统模板及未分类 UI 候选。别名、跨文件常量、普通字符串表和运行时内容须人工检查，零候选不能证明无漏译。

系统模板使用 AST 指纹提示配对复核，忽略注释、格式及 CRLF；`semanticApproval=false`，两种资源同时修改也不批准含义。同文件双语模块不推断改动语种，新增 owner 及间接依赖仍需人工分类。报告不改资源、不执行业务模板，也不自动运行其 `existingChecks`；P4 的 CI 接入尚未实施。

同步上游时核对新增文案、动态格式、模板身份、邮件入口、Markdown 解析、播放器的客户端/SSR 边界与父子任务语言；保留现有公开接口及领域边界，不借翻译复制业务流程。

2026-11-16 补齐新版未登录首页漏译：上游新增 `_public/route.tsx` 的导航直接显示英文，`SampleClipRow` 未传入已有样片名称翻译回调，生成按钮的未登录无障碍标签也未翻译。二开仅在这三处接入现有 `interface`、`presets`、`sequences` 资源；平台风格以 `isTemplate === true` 为界，自定义名称、源记录及试用链接 slug 保持原值。`script-view.tsx` 是既有超长文件，本次只修改标签，不附带拆分。后续上游调整公开布局、样片组装及匿名生成入口时须复核这些接入点。
