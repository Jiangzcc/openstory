# 首期验收清单

日期：2026-11-07。状态：范围修订；复用与二开分别验收，已撤销场景及历史未验证风险不作为本轮开发门槛。

本文件是 [首期功能规格](mvp-specification.md) 对应的验收要求，不是新增测试代码、实际执行报告或已经通过的结果。上游既有单元测试不能替代本项目的商业化验收；组织、组织钱包和兑换卡的既有能力只列作复用回归，不计为本项目新增功能。

2026-11-06 决定完整保留上游 Organization 的邀请、切换、共享、角色和组织钱包，取消个人人民币钱包及商业卡密改造，复用项目自带兑换卡。多租户权限隔离继续成立，按获授权组织和实际角色判断访问，不能把正常组织协作误判为跨租户越权。保留 A01–A41 编号供引用追踪，A14、A15、A17 对应的新增要求已撤销，不再算待执行开发门槛。

第一阶段已优先安排中文界面，独立验收见 [中文阶段计划](localization-plan.md)。中文阶段保留现有金额的真实币种，不因翻译就将上游美元展示为人民币。人民币模型销售单价及成本核算规划保留，售价如何衔接现有组织钱包尚待设计，不要求钱包或账本迁移，也不将微美元直接解释为人民币。

下表“复用回归”核对现有功能及其实际规则；“二开计划”保留已确认需求，待设计、实现后验证；“复用＋二开”分别记录现有基础与新增差异的证据，不代表整项为新增功能；“已撤销”不要求实施。A12 等历史未验证风险仅作风险记录，不自动成为本轮修复或交付门槛。国际化进度仍以独立计划及执行记录为准，本次不更新其他功能的实施状态。

## 2. 现有兑换卡与组织钱包

## 6. 执行与证据要求

- 每项记录环境、执行时间、输入类型、结果和证据位置；有效场景未执行或受环境阻碍就标为待验证，已撤销场景保持不适用，不计入待执行开发门槛。

- 真实模型验收需先明确可用账号与费用授权，记录使用范围和预算；本轮不发起任何调用。
- 演示数据和模拟供应商必须标注；模型 Mock 通过不等于真实供应商链路通过。
- 凭证、原始兑换码和隐私素材不进入公开截图或普通日志；证明权限和账务行为不依赖泄漏秘密。
- 实施后按实际变化选择测试，保留上游与二开验证来源，不将现有测试通过数算成本轮新增功能完成数。
