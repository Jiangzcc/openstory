## 3. 保留与升级边界

- **上游已有且保留**：组织邀请/切换/共享/角色及组织钱包、Stripe/兑换卡、原生与 fal 供应商路径、claim/选择指针/stopAt/continue、同 step 存媒体、API/MCP/OAuth、分享和导出。若核心文件没有净差异，按真实 blob 同一性和调用验证记录，不算二开新增。
- **二开已实现且有依据**：中英显示及独立系统指令资源、管理员模型配置、文本/图片渠道、冻结配置快照、安全身份分类/缓存代际，以及 Unicode 地点匹配等局部修正。组织凭证优先级和 Studio 管理员默认模型属于明确有意差异，不能为表面一致直接删掉。
- **已经取消**：个人独立人民币钱包、额外商业卡密、“管理员默认不浏览用户作品”等规划没有被本轮恢复为任务。
- **仍未实施**：全面禁 BYOK、人民币销售定价/成本换算和默认私有媒体。现有 USD/microdollar 不解释为人民币，不裁剪现有组织/API/MCP 能力。

一个已知非阻断显示缺口仍单列：模型选择器可能原样显示动态英文能力错误；这不构成上游能力丢失，也未借 P2 开展全面本地化重构。
