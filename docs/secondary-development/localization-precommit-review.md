## 接入方式与上游升级关注点

- 新增翻译资源及显示适配器放在既有平台/应用国际化层或对应领域 UI 中；根布局、Router、账号邮件及公共组件只接必要桥接。没有增加领域依赖豁免、业务表字段或另一套模型校验。
- 参考素材提示只匹配已知完整英文模板，重复参数必须一致，存在多种合法拆分或上游出现未知格式时原样回退；素材标识、角色名、模型名和服务端记录保留。上游提示模板调整时同步核对适配器和两种语言资源。
- 生成计划和草稿辅助函数以可选翻译参数扩展；不传参时保留上游英文输出，调用条件、空值、请求参数及数据库内容不随语言改变。
- 角色详情文件单独提取首次出现位置这一显示职责，恢复到 800 行以内；素材选择器上游原为 800 行、翻译接入后为 837 行，单独提取素材卡片显示后为 790 行，新组件 80 行，上传、重命名及删除决策仍在原调用处。其他继承的超长上游页面仅改必要文案接入，没有借国际化扩张重构。
- i18next/react-i18next 接入、资源键、元信息标记、Hook 订阅及 Trans 插值行为是上游组件更新和依赖升级时的复核点。富文本防重复插值使用公开选项，没有修改依赖源码。
- 原有脚本、计价字段、币种、供应商请求、生成条件、权限与工作流仍沿用上游。人民币卡密及禁用 BYOK 等商业需求仍是规划，不计入本次实现。
- .gitignore 中的 .idea 用于排除本地 IDE 文件；bun.lock 除两个国际化依赖外，包含安装器对已有依赖的归一化：去除重复 durable-stream 包记录并与 package.json 中已有的 @tanstack/ai-client 保持同步，没有扩大业务依赖升级范围。
