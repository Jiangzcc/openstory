# 中英文系统指令

日期：2026-11-07。实施基线：`develop` 的 `3b203b3b6c644ab29014ba3860c2667f53cd00da`；上游合入基线为 `003e2df7c4986fc236ea9a1c67c3f18089874d48`。本轮已按用户授权完成代码改造和下述本地验证；提交状态以 Git 记录为准，未推送或部署。

## 需求与原有行为

上游已有代码内模板、业务上下文组装、异步工作流及作品提示词版本管理；二开已有默认简体中文、可切换英文的界面及语言 Cookie。系统指令此前没有语言选择，主要使用英文。本轮新增的能力是按网页界面语言选择系统指令，不新增模板管理后台、作品翻译或版本管理系统。

中文用户使用中文系统指令，英文用户使用原有英文指令。用户查看、编辑、恢复的仍是实际保存的内容。系统指令使用中文不意味着强制翻译剧本、对白或所有模型输出。项目尚未上线，本轮不兼容缺少语言的历史任务。

## 语言契约

- 复用 `Locale`，内部上下文和工作流载荷使用必填的 `promptLocale`。
- 网页请求从 `openstory_locale` Cookie 确定语言，没有选择或值无效时默认 `zh-CN`。
- 助手从自己的原始 Request 确定语言，再经内部 MCP 上下文传给共享服务。
- 外部 API/MCP 保留英文默认值，入口显式赋值，不新增公开语言参数。
- 创建新任务时传入该次请求的语言；子任务和自动重试沿用该任务的语言。幂等复用已有实例时不重写原载荷，不因语言改变幂等键或扣费规则。
- 任务执行时不读取 Cookie，不使用进程级可变语言，不把语言放入 ScopedDb 或数据库插入数据。工作流消费边界拒绝缺少或无效的语言。

## 模板与覆盖

主注册表英文资源保持原文，中文资源按职责放在 `src/platform/server/ai/prompts/zh-CN/`。`getPrompt(name, variables, locale)` 和 `getChatPrompt(name, variables, locale)` 显式选择语言，继续使用原有变量替换。未知模板仍报错；中文资源缺项回退已有英文，目录完整性由测试约束。

## 保存与协议边界

不新增表、字段或迁移，不将语言加入 `inputHash`，不因切换界面语言触发历史提示词过期。参考素材计划等纯内容 DTO 不携带语言，真正创建子任务时再加入语言。

画面和视频提示词沿用原有版本保存；音乐也保留原有相同业务摘要复用规则。音乐重写可能直接返回 `alreadyUpToDate` 而不调用模型，保存时也可能复用同摘要的已有行。验收目标是实际模型调用的指令语言正确，不保证切换语言会重新生成或保存另一语种文本。

JSON 字段、枚举、变量名、引用 token、素材绑定和供应商 markup 保持不变。中文润色指令保留 `Scene N — Xs` 和 `TOTAL:`，因为代码解析这些格式。2026-11-07 后续风格改造已将中文软化模板的自由描述要求改为中文，英文模板保持原文；内容与安全约束继续有效。MiniMax 的 `[English]` 等既有对白适配不从 UI locale 推断对白语言。

初次系统指令改造未整体翻译直接派生的镜头作品提示词、参考图渲染文本及供应商最终请求适配。2026-11-07 用户后续授权的[风格双语改造](style-localization.md)已补齐平台预置配方、示例和相关自然语言组装，并明确中文新创作描述的输出要求。供应商最终请求仍不作整体翻译；用户的输入、命名、引用、对白及保存历史不自动转换。

## 必要桥接与上游升级

新增职责集中在语言工具和独立资源模块；修改既有入口以传递语言，未复制生成、授权、计费或存储流程。必要上游接入点包括请求中间件、内部 MCP 上下文、工作流输入类型、launcher、父子任务组装、LLM helper 和领域内独立指令入口。

上游升级时核对：新增或变化的模板和变量、所有直接 LLM 入口、手工构造的子任务载荷、助手工具上下文、响应格式约束、素材分类安全规则及 Mock 匹配方式。英文模板规则变化须同步审校中文，而不是只保证模板名称存在。
